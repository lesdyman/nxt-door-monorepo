## Import order

Always sort imports in this order, with a blank line between each group:

1. React / React Native core (`react`, `react-native`)
2. Third-party libraries (`expo-*`, `tamagui`, `lucide-react-native`, `react-native-modal`, etc.)
3. Absolute / alias imports (`@constants/*`, `@components/*`, `@assets/*`)
4. Local relative imports (`./components/*`, `../utils/*`, etc.)
